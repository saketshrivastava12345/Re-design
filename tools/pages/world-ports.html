Codes are for reference, not for filing. UN/LOCODE assignments change, and several of these ports have more than one code for different terminals or for the airport in the same city. Confirm the code against the UN/LOCODE register or your carrier's booking note before it goes on a document.

Reading a LOCODE

Five letters, two halves

A UN/LOCODE is two letters of ISO country code followed by three letters for the place: IN + NSA for Nhava Sheva, NL + RTM for Rotterdam.

It is the identifier that ties a booking, a customs filing and a carrier's schedule to the same physical place, which matters more than it sounds — there are Springfields and Victorias on four continents, and a dozen ports called Puerto Nuevo.

  • The same code covers the sea port and, often, the airport of a city — the function field in the register tells you which.
  • Large ports have separate codes for individual terminals; carriers may quote either.
  • Inland container depots and dry ports have their own codes, which is what makes door-to-door multimodal documentation work.
